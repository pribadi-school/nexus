# Design

Nexus uses the shared Pribadi design system. This file only points to it.

1. **Brand:** [design-system/sekolah-pribadi-depok/MASTER.md](design-system/sekolah-pribadi-depok/MASTER.md). This is the school's design system, shared with the website, the uniform app and the Parent–Teacher Consultation app. It is a copy, so if the brand changes, update every copy.
2. **This app's rules:** [design-system/sekolah-pribadi-depok/pages/nexus-app.md](design-system/sekolah-pribadi-depok/pages/nexus-app.md). These are the Nexus brand palette, the flat app style shared by every Pribadi app, the device status colours and the logo rules. Where they differ, this file wins over MASTER.md.
3. **Tokens:** [public/assets/css/tokens.css](public/assets/css/tokens.css) (`:root`). Every colour, radius and type size comes from a token there.

In short, Nexus uses:
- Inter for the UI, Space Grotesk for the "nexus" wordmark, IBM Plex Sans for the tagline
- brand blue `#1F4E9F` for actions, red `#B91C1C` for problems, navy `#0F2A5C` for dark surfaces
- a `#f2f5f9` page with white cards and 1px navy-tinted borders
- 8px buttons, and no shadows, gradients or icon tiles
- a word next to every status colour
